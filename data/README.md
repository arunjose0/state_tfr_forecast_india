# Data Sources

This directory contains the cleaned, aggregated datasets used for fitting the TFR models. 

The original raw data underlying these cleaned datasets comes from the following public sources:

1. **2011 Census of India Data**:
   - Source: Office of the Registrar General & Census Commissioner, India.
   - Used for extracting population weights for bifurcated states.

2. **Sample Registration System (SRS) Reports**:
   - Source: Sample Registration System Statistical Reports, Office of the Registrar General, India.
   - Used for annual state-level Total Fertility Rates (TFR) across the historical period.

3. **National Family Health Survey (NFHS) Data**:
   - Source: International Institute for Population Sciences (IIPS) and ICF.
   - Used for periodic state-level fertility estimates from NFHS rounds 1 through 5.

Due to file size constraints and because the raw data is available directly from the original sources, only the final pre-processed analytical datasets required to run the model are included in this repository.
